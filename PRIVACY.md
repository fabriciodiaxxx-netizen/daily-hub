# Privacidad — analítica de visitas

Daily Hub registra una visita al cargar la aplicación para seguridad básica y estadísticas de uso.

## Datos registrados

- fecha y hora del servidor;
- dirección IP recibida por el proxy/servidor;
- agente de usuario (navegador y sistema, truncado a 512 caracteres);
- ruta de la aplicación, sin parámetros ni fragmentos;
- código de país de dos letras sólo si el proxy lo entrega.

No se registran el contenido de recordatorios, notas, credenciales, correo, identificadores de publicidad, cookies de analítica, referrer ni parámetros de URL. La IP no se obtiene con JavaScript: la determina el servidor.

Los registros no se exponen al público ni a usuarios autenticados. Se usan únicamente para operar y proteger Daily Hub. Se elimina o anonimiza la información de más de 30 días. Para consultas sobre estos datos, contactá a la persona responsable de Daily Hub.
